# لایهٔ دادهٔ شاهنشاهی

این پوشه نسخهٔ قابل نگهداری از لایهٔ دادهٔ پروژه را نگه می‌دارد.

## منبع داده

`../database-dump-2026-09-13.sql` یک PostgreSQL dump از نسخهٔ دیتابیس بازی است. این dump شامل schema و seed data برای وضعیت بازی، استان‌ها، شخصیت‌ها، روابط، رویدادها، گروه‌های اجتماعی، جنگ‌ها، چالش‌ها، حافظهٔ تاریخی و logهاست.

## نکتهٔ مهم برای GitHub Pages

نسخهٔ فعلی بازی روی GitHub Pages کاملاً client-side است و PostgreSQL را مستقیماً اجرا نمی‌کند. بنابراین dump را به عنوان منبع schema/داده نگه می‌داریم و منطق بازی مرورگر را از آن جدا می‌کنیم. اتصال واقعی به PostgreSQL در مرحلهٔ بعد باید از طریق یک API امن انجام شود؛ credentials نباید داخل `index.html` قرار بگیرند.

## نگاشت اصلی

- `game_state` → وضعیت سراسری بازی
- `game_provinces` → استان‌ها و منابع
- `game_characters` → شخصیت‌ها
- `game_character_relations` → روابط شخصیت‌ها
- `game_events` → رویدادهای تاریخی/انتقالی/اجتماعی
- `game_groups` → گروه‌های اجتماعی
- `game_relations` → روابط با قدرت‌ها
- `game_wars` → جنگ‌ها
- `game_challenges` → چالش‌ها
- `game_history_memory` → حافظهٔ تاریخی
- `game_logs` → تاریخچهٔ رخدادهای بازی

## وضعیت ادغام

نسخهٔ client-side فعلی عمداً دست‌نخورده مانده تا منطق موجود بازی خراب نشود. لایهٔ داده ابتدا به صورت adapter جدا ساخته می‌شود و بعد قابلیت‌های بازی یکی‌یکی به آن متصل خواهند شد.
