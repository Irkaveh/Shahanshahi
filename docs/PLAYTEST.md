# Playtest guide

## Quick start

Open index.html in a modern browser.

## Smoke test

1. Select several provinces on the map.
2. Select the army and move it to an adjacent province.
3. Split and merge an army.
4. Recruit troops after checking food and treasury.
5. Use tax, trade, water, irrigation, law, and science actions.
6. Advance one year and then several years.
7. Save the game, reload the page, and verify that the state returns.
8. Check the historical timeline as the year advances.
9. Open the war, diplomacy, economy, and court tabs.
10. Exercise the espionage and secret-ring systems.

## Reporting a bug

Include:
- browser and device;
- exact steps to reproduce;
- expected result;
- actual result;
- whether the problem survives a fresh game reset;
- console error text, if available.

Screenshots or a short screen recording are useful when the bug is visual.
